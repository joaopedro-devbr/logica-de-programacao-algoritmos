# Java

Exercícios de lógica de programação e algoritmos desenvolvidos em Java.

Nesta etapa, são trabalhados conceitos como:

* Estruturas sequenciais
* Estruturas condicionais
* Estruturas repetitivas
* Vetores
* Matrizes

Os exercícios têm como objetivo praticar a lógica de programação e desenvolver a capacidade de resolver problemas utilizando a linguagem Java.
